# User Stories

## 1. Registrierung Öffnen

Als neuer User möchte ich vom Login Screen zur Registrierung wechseln, damit ich ein neues Konto erstellen kann.

Akzeptanzkriterien:
- Gegeben ich bin auf dem Login Screen
- Wenn ich auf Registrieren tippe
- Dann öffnet sich der Register Screen

## 2. Registrierung Durchführen

Als neuer User möchte ich mich mit E-Mail, Passwort und Benutzername registrieren, damit ich Pulse nutzen kann.

Akzeptanzkriterien:
- Gegeben ich bin auf dem Register Screen
- Wenn ich gültige Daten eingebe und absende
- Dann wird mein Konto erstellt

## 3. Nach Registrierung Weiterleiten

Als neuer User möchte ich nach erfolgreicher Registrierung direkt in die App gelangen, damit ich sofort starten kann.

Akzeptanzkriterien:
- Gegeben meine Registrierung war erfolgreich
- Wenn der Vorgang abgeschlossen ist
- Dann werde ich zum Home Feed weitergeleitet

## 4. Login Durchführen

Als registrierter User möchte ich mich einloggen, damit ich Zugriff auf mein Konto habe.

Akzeptanzkriterien:
- Gegeben ich bin auf dem Login Screen
- Wenn ich gültige Login-Daten eingebe
- Dann werde ich eingeloggt

## 5. Login-Fehler Anzeigen

Als User möchte ich bei falschen Login-Daten eine Meldung sehen, damit ich den Fehler korrigieren kann.

Akzeptanzkriterien:
- Gegeben ich gebe falsche Login-Daten ein
- Wenn ich auf Login tippe
- Dann sehe ich eine verständliche Fehlermeldung

## 6. Logout Durchführen

Als eingeloggter User möchte ich mich ausloggen, damit mein Konto auf dem Gerät geschützt ist.

Akzeptanzkriterien:
- Gegeben ich bin eingeloggt
- Wenn ich auf Logout tippe
- Dann werde ich zum Login Screen weitergeleitet

## 7. Auth-Status Prüfen

Als User möchte ich beim App-Start automatisch richtig weitergeleitet werden, damit ich nicht jedes Mal unnötig einloggen muss.

Akzeptanzkriterien:
- Gegeben ich bin bereits eingeloggt
- Wenn ich die App öffne
- Dann sehe ich direkt den Home Feed

## 8. Eigenes Profil Anzeigen

Als User möchte ich mein Profil anzeigen, damit ich meine Informationen sehen kann.

Akzeptanzkriterien:
- Gegeben ich bin eingeloggt
- Wenn ich den Profile Screen öffne
- Dann sehe ich meinen Benutzernamen und meine Bio

## 9. Eigene Beiträge Im Profil Anzeigen

Als User möchte ich meine eigenen Beiträge im Profil sehen, damit ich meine Inhalte gesammelt finde.

Akzeptanzkriterien:
- Gegeben ich habe eigene Beiträge erstellt
- Wenn ich mein Profil öffne
- Dann werden meine Beiträge angezeigt

## 10. Profil Bearbeiten

Als User möchte ich mein Profil bearbeiten, damit ich meine Angaben aktualisieren kann.

Akzeptanzkriterien:
- Gegeben ich bin auf dem Edit Profile Screen
- Wenn ich neue Profildaten speichere
- Dann werden die Änderungen übernommen

## 11. Benutzername Ändern

Als User möchte ich meinen Benutzernamen ändern, damit mein Profil aktuell bleibt.

Akzeptanzkriterien:
- Gegeben ich gebe einen gültigen neuen Benutzernamen ein
- Wenn ich speichere
- Dann wird der neue Benutzername angezeigt

## 12. Bio Ändern

Als User möchte ich meine Bio ändern, damit andere mehr über mich erfahren können.

Akzeptanzkriterien:
- Gegeben ich gebe eine neue Bio ein
- Wenn ich speichere
- Dann wird die neue Bio im Profil angezeigt

## 13. Beitrag Erstellen

Als User möchte ich einen Beitrag erstellen, damit ich Inhalte teilen kann.

Akzeptanzkriterien:
- Gegeben ich bin auf dem Create Post Screen
- Wenn ich einen gültigen Text veröffentliche
- Dann wird der Beitrag gespeichert

## 14. Beitrag Im Feed Anzeigen

Als User möchte ich neue Beiträge im Feed sehen, damit ich aktuelle Inhalte lesen kann.

Akzeptanzkriterien:
- Gegeben ein Beitrag wurde erstellt
- Wenn ich den Feed öffne
- Dann wird der Beitrag angezeigt

## 15. Feed Sortieren

Als User möchte ich die neuesten Beiträge zuerst sehen, damit der Feed aktuell wirkt.

Akzeptanzkriterien:
- Gegeben mehrere Beiträge existieren
- Wenn der Feed geladen wird
- Dann stehen die neuesten Beiträge oben

## 16. Leeren Feed Anzeigen

Als User möchte ich einen Hinweis sehen, wenn es noch keine Beiträge gibt, damit der Screen nicht leer wirkt.

Akzeptanzkriterien:
- Gegeben es existieren keine Beiträge
- Wenn ich den Feed öffne
- Dann sehe ich einen passenden leeren Zustand

## 17. Beitrag Liken

Als User möchte ich einen Beitrag liken, damit ich meine Zustimmung zeigen kann.

Akzeptanzkriterien:
- Gegeben ich habe einen Beitrag noch nicht gelikt
- Wenn ich auf Like tippe
- Dann wird der Beitrag gelikt

## 18. Beitrag Unliken

Als User möchte ich meinen Like entfernen, damit ich meine Reaktion ändern kann.

Akzeptanzkriterien:
- Gegeben ich habe einen Beitrag bereits gelikt
- Wenn ich erneut auf Like tippe
- Dann wird mein Like entfernt

## 19. Like-Anzahl Anzeigen

Als User möchte ich die Anzahl der Likes sehen, damit ich erkenne, wie beliebt ein Beitrag ist.

Akzeptanzkriterien:
- Gegeben ein Beitrag hat Likes
- Wenn der Beitrag angezeigt wird
- Dann sehe ich die Like-Anzahl

## 20. Kommentare Öffnen

Als User möchte ich die Kommentare eines Beitrags öffnen, damit ich die Diskussion lesen kann.

Akzeptanzkriterien:
- Gegeben ich sehe einen Beitrag
- Wenn ich auf Kommentare tippe
- Dann öffnet sich der Comments Screen

## 21. Kommentar Erstellen

Als User möchte ich einen Kommentar schreiben, damit ich auf einen Beitrag reagieren kann.

Akzeptanzkriterien:
- Gegeben ich bin auf dem Comments Screen
- Wenn ich einen gültigen Kommentar absende
- Dann wird der Kommentar gespeichert

## 22. Kommentare Anzeigen

Als User möchte ich bestehende Kommentare sehen, damit ich die Reaktionen anderer lesen kann.

Akzeptanzkriterien:
- Gegeben ein Beitrag hat Kommentare
- Wenn ich den Comments Screen öffne
- Dann werden die Kommentare angezeigt

## 23. Kommentar-Anzahl Anzeigen

Als User möchte ich die Anzahl der Kommentare im Feed sehen, damit ich erkenne, ob ein Beitrag diskutiert wird.

Akzeptanzkriterien:
- Gegeben ein Beitrag hat Kommentare
- Wenn der Beitrag im Feed angezeigt wird
- Dann sehe ich die Kommentar-Anzahl

## 24. Eigenen Beitrag Löschen

Als User möchte ich meine eigenen Beiträge löschen, damit ich Kontrolle über meine Inhalte habe.

Akzeptanzkriterien:
- Gegeben ich sehe einen eigenen Beitrag
- Wenn ich ihn lösche
- Dann verschwindet der Beitrag aus dem Feed

## 25. Fremde Beiträge Nicht Löschen

Als User möchte ich fremde Beiträge nicht löschen können, damit Inhalte anderer geschützt sind.

Akzeptanzkriterien:
- Gegeben ich sehe einen fremden Beitrag
- Wenn der Beitrag angezeigt wird
- Dann sehe ich keine Löschoption

## 26. Eingaben Validieren

Als User möchte ich Hinweise bei ungültigen Eingaben erhalten, damit ich Formulare korrekt ausfüllen kann.

Akzeptanzkriterien:
- Gegeben ein Pflichtfeld ist leer
- Wenn ich das Formular absende
- Dann sehe ich eine Validierungsmeldung

## 27. E-Mail Validieren

Als User möchte ich bei einer ungültigen E-Mail-Adresse einen Hinweis sehen, damit ich sie korrigieren kann.

Akzeptanzkriterien:
- Gegeben ich gebe eine ungültige E-Mail-Adresse ein
- Wenn ich Login oder Registrierung absende
- Dann sehe ich eine Fehlermeldung

## 28. Passwort Validieren

Als User möchte ich bei einem zu kurzen Passwort einen Hinweis sehen, damit mein Konto sicherer ist.

Akzeptanzkriterien:
- Gegeben mein Passwort ist zu kurz
- Wenn ich mich registrieren möchte
- Dann sehe ich eine Validierungsmeldung

## 29. Ladezustand Anzeigen

Als User möchte ich Ladezustände sehen, damit ich weiß, dass die App arbeitet.

Akzeptanzkriterien:
- Gegeben Daten werden geladen
- Wenn ich einen Screen öffne
- Dann sehe ich einen Ladeindikator

## 30. Buttons Während Laden Sperren

Als User möchte ich während einer laufenden Aktion keine Buttons mehrfach drücken können, damit keine doppelten Aktionen entstehen.

Akzeptanzkriterien:
- Gegeben eine Aktion wird gerade ausgeführt
- Wenn der Ladevorgang läuft
- Dann ist der betroffene Button deaktiviert

## 31. Fehler Verständlich Anzeigen

Als User möchte ich verständliche Fehlermeldungen sehen, damit ich weiß, was passiert ist.

Akzeptanzkriterien:
- Gegeben ein technischer Fehler tritt auf
- Wenn eine Aktion fehlschlägt
- Dann sehe ich eine einfache Fehlermeldung

## 32. Netzwerkfehler Anzeigen

Als User möchte ich bei Verbindungsproblemen informiert werden, damit ich die Aktion später erneut versuchen kann.

Akzeptanzkriterien:
- Gegeben keine Internetverbindung besteht
- Wenn Daten geladen oder gespeichert werden
- Dann sehe ich eine Meldung zum Verbindungsproblem
