# Claude Code Instructions

Follow the same repository rules as `.cursorrules` and `AGENTS.md`.

- Preserve the school-project scope: no reels, stories, live chat, or unnecessary production-scale complexity.
- Mobile client is Flutter with Dart in `pulse-flutter/`. Do not extend the legacy `pulse-android/` Java skeleton.
- Keep secrets out of Git.
- Update docs and diagrams when architecture changes.
- Run `mvn -B clean test` from `pulse-backend` for backend changes.
- Run `flutter analyze` and `flutter test` from `pulse-flutter/` for mobile changes.
- Respect existing team roles, Scrum documentation, and issue references.
- Pull requests target `main` only.
