# Mini Social Media App

Dieses Repository enthält ein Schulprojekt für das Modul 335 - Mobile-Applikation realisieren.

Ziel ist eine einfache Social-Media-App mit Flutter. User sollen sich registrieren und einloggen können, ein Profil besitzen, Beiträge erstellen, einen Feed ansehen, Beiträge liken und kommentieren können.

## Projektart

- Modul: 335 - Mobile-Applikation realisieren
- Vorgehensmodell: Scrum
- Projektdauer: 5 Wochen
- Technologie: Flutter
- Backend: Firebase

## Geplante Hauptfunktionen

- Registrierung
- Login und Logout
- Profil anzeigen und bearbeiten
- Beitrag erstellen
- Feed anzeigen
- Beiträge liken und unliken
- Beiträge kommentieren
- Eigene Beiträge löschen
- Validierung von Eingaben
- Ladezustände und Fehlermeldungen

## Firebase

Für das Projekt sind folgende Firebase-Dienste geplant:

- Firebase Authentication für Registrierung, Login und Logout
- Cloud Firestore für User, Beiträge, Likes und Kommentare
- Firebase Storage optional für Profilbilder oder Beitragsbilder

Der Fokus liegt auf einer stabilen, einfachen und präsentierbaren App. Funktionen wie Reels, Storys, Live-Chat, private Nachrichten oder Push Notifications werden bewusst weggelassen.
